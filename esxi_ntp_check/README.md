# ESXi через vCenter: шаблон Zabbix и дашборд Grafana

Мониторинг конфигурации и состояния ESXi-хостов через vCenter (pyVmomi). Производительность и железо
сюда не входят: их закрывают стандартный шаблон **VMware** и SNMP по HPE.

| Файл | Что это |
|---|---|
| `Template ESXi Health by vCenter.yaml` | шаблон Zabbix 7.0: один сборщик + зависимые элементы и LLD |
| `esxi_ntp_check.py` | скрипт (External check), кладётся в `/usr/lib/zabbix/externalscripts/`; нужен venv `/opt/zabbix-venv` с pyVmomi 8.0.3+ |
| `grafana/esxi-health.json` | дашборд Grafana «VMware ESXi — здоровье хостов (vCenter)» |
| `tools/gen_esxi_dashboard.py` | генератор дашборда (`grafana/esxi-health.json` руками не правится) |
| `Template ESXi NTP LLD.yaml` | прежний шаблон (ключи другие, оставлен для миграции) |
| `CHANGES.md` | что менялось и что осталось проверить на стенде |

## Что проверяется

NTP (настроен + ntpd запущен, смещение времени относительно vCenter), DNS, VMkernel, Storage-адаптеры,
Power policy, dead-пути мультипасинга, недоступные датасторы, HA-агент, физические порты-аплинки и vSwitch/DVS
(линк, скорость, число живых аплинков). Хост в Maintenance Mode или не в `connected` не алертит.

## Дашборд Grafana

Нужны плагин Zabbix (`alexanderzobnin-zabbix-app`) и источник данных Zabbix.
*Dashboards → New → Import* → `grafana/esxi-health.json` → выбрать источник.
Переменная «vCenter (мастер-хост)» — хост Zabbix, к которому привязан шаблон (по одному на каждый vCenter).

Сверху вниз:

1. **Светофор** — 14 плиток, зелёное «OK» или число хостов не в норме: данные vCenter, предупреждения сборщика,
   хосты с выключенными алертами, NTP, смещение времени, DNS, Power policy, VMkernel, Storage-адаптеры,
   dead-пути, датасторы, HA-агент, линки аплинков, vSwitch без аплинков.
2. **Активные проблемы** Zabbix по мастер-хосту.
3. **Карта** — плитка на каждый ESXi-хост для каждой проверки.
4. **Сеть** — линк каждого порта (хост · vmnic), живые аплинки vSwitch, скорость линка.
5. **Хранилище и время** — динамика dead-путей, недоступных датасторов и смещения времени (линии порогов ±1 и ±5 с).
6. **История** — когда менялись NTP, HA-агент, подавление алертов, адаптеры хранилища, линки, power policy.

Пороги на дашборде совпадают со значениями макросов шаблона по умолчанию (`{$ESXI.NTP.OFFSET.WARN}` = 1,
`{$ESXI.NTP.OFFSET.HIGH}` = 5); тест проверяет это. Если вы поменяли макросы, поправьте и дашборд.

Элементы фильтруются по именам вида `NTP configured on <хост>`, поэтому переименование элементов в шаблоне
нужно повторить в генераторе (`tools/gen_esxi_dashboard.py`): тест `tests/test_grafana.py` сразу покажет расхождение.

Скриншот в репозиторий не добавлен: дашборд проверен тестами (привязка к элементам шаблона, value map,
раскладка), но не отрисован в живой Grafana.
